OmniLogs combines various third-party Twitch log providers into a single, clean UI with extra features, such as automatic selection of log providers for specific channels, full day/month/year chat history, filtering by specific words or phrases, and optional user-specific log searches in a given channel.

OmniLogs was created by UmbraGG using the free tier of Claude Sonnet 5 to see how far an AI model could go with no prior coding experience whatsoever. I don't plan on hosting or actively maintaining this project, it was just an idea I had and I wanted to see if it was possible to create without any programming skills using a free tier, publicly available AI model.

If you want, you can grab the code and expand on it yourself, or do whatever you want with it. All of the work was generated by the Claude Sonnet 5. I just had some ideas and wanted to see if it was possible to make them come true. 😉
