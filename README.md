OmniLogs combines various third-party Twitch log providers into a single, clean UI with extra features, such as automatic selection of log providers for specific channels, full daily/monthly/yearly chat history, filtering by specific words or phrases, and optional user-specific log searches in a given channel.

OmniLogs is a personal project created by UmbraGG to test whether a fully functional website could be built with no programming skills whatsoever, using only the free-tier models of Claude Sonnet 5 and DeepSeek. I don't plan on hosting or actively maintaining this project, it was just an idea I wanted to test out.

Feel free to grab the code and expand on it, or do whatever you'd like with it. All of the work was generated by the Claude Sonnet 5 and DeepSeek AI models. I just provided the ideas. 😉
